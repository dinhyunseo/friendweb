Индивидуальное семестровое задание по
Frontend-разработке
Цель: Разработать frontend-часть веб-приложения, с использованием одного
из фреймворка/библиотеки для SPA-приложения.
Стек технологий:
● Язык: TypeScript
● Библиотека: React (функциональные компоненты + хуки)
● Роутинг: React Router DOM
● Управление состоянием: Mobx/Redux Toolkit/Zustand/Jotai (или Context
API для сложных форм, но глобальное состояние — на RTK)
● Запросы к API: Axios / Fetch API
● Стилизация (на выбор): CSS Modules, Styled Components, Tailwind CSS.
* можно выбрать фреймворк Vue/Angular, использование ванильного JS или
библиотек (JQuery) нельзя

Функциональные требования (обязательные для всех тем):
1 Авторизация и аутентификация:
○ Реализация формы входа/регистрации.
○ Механизм хранения токена (JWT) и его передачи при запросах.
○ Защищённые (приватные) и публичные маршруты.
2 Разделение по ролям:
○ Как минимум две роли (например, Пользователь и Администратор,
Студент и Преподаватель, Клиент и Менеджер).
○ Разный интерфейс и функционал в зависимости от роли
(навигация, доступные действия, отображаемые данные).
3 Работа с глобальным состоянием:
○ Использование одной из библиотек для управления глобальными
данными (например, информация о пользователе, уведомления,
загрузка данных приложения).
4 Адаптивный интерфейс:
○ Приложение должно корректно отображаться и быть удобным в
использовании для 2 разрешений: 1 десктопное, 1 мобильное
(разрешение студент выбирает сам).
5 Работа с большими и сложными формами:
○ Реализовать минимум одну сложную форму, помимо авторизации
(например, форма бронирования с множеством полей, форма
создания сложной задачи, форма подачи заявления).
○ Обязательно: валидация полей (можно использовать Formik + Yup
или React Hook Form).
○ Удобный UX: индикация ошибок, подсказки, многошаговость
(wizard form) приветствуется.
6 Работа с вебсокетами:
○ Реализовать в реальном времени один из двух
функциональностей на выбор:
■ Чат (личный или групповой, в зависимости от темы).
■ Система мгновенных уведомлений (например, о
подтверждении брони, изменении статуса заказа, новом
сообщении от преподавателя).
